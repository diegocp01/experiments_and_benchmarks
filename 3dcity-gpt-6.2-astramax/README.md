# Cityform

Run `python3 -m http.server 4173 --bind 127.0.0.1` in this directory and open [the explorer](http://127.0.0.1:4173). The project includes Three.js and works offline in a WebGL 2 browser.

- Drag to orbit, right-drag to pan, and scroll to zoom. On a touchscreen, drag with one finger or pan and pinch with two.
- Select **Fly** for a street-level view. Use **WASD** to move, drag to look, and use **E/Q** to climb or descend. Click the scene to capture the mouse. **Shift** speeds up flight and **Esc** returns to orbit. Touch devices have an on-screen flight pad.
- **Regenerate city** picks a new seed. Enter a seed and press **Enter** to recreate a layout. The address bar includes the current seed.
- Use **Day** and **Night** to change the lighting. Click the city map to move the camera to that location.
